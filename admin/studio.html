設定

単語を登録したときに GitHub Actions で学習を走らせるための設定。 トークンはこの端末にだけ保存され、リポジトリには入らない。

GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で作る。 対象はこのリポジトリだけ、権限は Contents の Read and write でいい。期限は短めに。
